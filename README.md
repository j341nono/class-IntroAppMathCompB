# 数理情報基礎B

数理情報基礎Bの授業課題をまとめたリポジトリです。各課題は対応する
`homework*/` ディレクトリに配置しています。

## ディレクトリ構成

```text
.
├── homework2/   # Homework 2
├── homework3/   # Homework 3: IITのパリティ例
├── homework4/   # Homework 4
├── homework5/   # Homework 5: 1次元力学系のMorse分解
├── homework6/   # Homework 6: 講義で学んだ内容の英語レポート
└── homework7/   # Final Assignment: Heritable Prompt Information
```

| ディレクトリ | 内容 |
|---|---|
| `homework2/` | Homework 2の提出物 |
| [`homework3/`](homework3/) | IITのパリティ例 |
| [`homework4/`](homework4/) | Homework 4用ディレクトリ |
| [`homework5/`](homework5/) | 1次元力学系のMorse分解 |
| [`homework6/`](homework6/) | 講義で学んだ内容を英語300語以内でまとめ、PDFで提出する課題 |
| [`homework7/`](homework7/) | **最終レポート（Final Assignment）** |

## 最終レポート

この授業の最終レポートは [`homework7/`](homework7/) にあります。

最終レポートでは、自動プロンプト最適化のための独自の情報量 Heritable Prompt Information (HPI) を提案し、Pythonによる再現可能な実験を行っています。
詳細な説明、数式、実行方法、実験結果および図は
[`homework7/README.md`](homework7/README.md) を参照してください。
